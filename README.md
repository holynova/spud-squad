## 操作

- **WASD / 方向键** — 移动
- **空格** — 冲刺（短暂无敌）
- 武器自动攻击最近敌人

## 内容

- **5个角色**：战士、射手、法师、刺客、坦克，各有独特属性和技能
- **8种武器**：霰弹枪、冲锋枪、狙击枪、火箭筒、特斯拉、冰冻射线、轨道炮、飞刀
- **8种敌人 + 3个Boss**，**20波次**，升级三选一卡片系统
- 丰富粒子效果：射击轨迹、命中火花、死亡爆炸、屏幕震动

## 技术

Three.js + Vite，纯ES Modules，无框架依赖。
